# Writing templates

이 디렉터리는 게시되는 콘텐츠가 아니라 새 글을 시작하기 위한 뼈대입니다.

## 사용법

1. 글의 성격에 맞는 템플릿을 복사합니다.
   - 긴 생각과 해석을 전개하는 글: `essay.md`
   - 짧은 관찰, 기술 기록, 진행 중인 생각: `note.md`
2. 복사한 파일을 `src/content/writing/<slug>.md`에 둡니다.
3. frontmatter의 제목, 설명, 날짜, 태그를 수정합니다.
4. 작성 중에는 `draft: true`를 유지합니다.
5. 공개할 때 `draft: false`로 바꿉니다.

템플릿 안의 질문과 소제목은 고정 형식이 아닙니다. 글을 시작하기 위한 발판으로만 사용하고, 실제 글에서는 자유롭게 삭제하거나 재배열합니다.

AI는 템플릿 설계, 질문 제안, 편집과 검토를 맡을 수 있지만, 실제 경험과 판단을 대신 작성하지 않는 것을 기본 원칙으로 합니다.
